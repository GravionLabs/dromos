# 001: Product name is Dromos

Status: accepted

## Context
The project started as `agent-bus`, a name that describes the mechanism and not the product (see #70).

## Decision
The product is named Dromos. `agent-bus` is retired.

## Rationale
One distinct name for the runner, the bus and the plugins avoids confusion with generic "agent bus" projects.

## Consequences
Code, docs and package names use `dromos`. New material must not reintroduce `agent-bus`.
